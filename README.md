# 📊 Power BI Sales Report

## 📌 Overview
This Power BI report provides a **comprehensive sales analysis** by visualizing:
- **Total Sales, Total Profit, and Order Count**
- **Monthly Sales & Profit Trend**
- **Sales Distribution by Region**

## 📈 Key Insights
- **Sales Trend:** Identifies seasonal patterns in sales and profit.
- **Regional Sales:** Highlights sales concentration across different regions.
- **Total Metrics:** Displays KPIs like Total Sales, Profit, and Order Count.

## 🚀 How to Use
1. Download the `.pbix` file from this repository.
2. Open it using **Power BI Desktop**.
3. Refresh the dataset if needed.
